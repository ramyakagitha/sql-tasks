12)Explain the different types of SQL command languages?
1.DDL (Data Definition Language):Used to define database structure.
Commands:
CREATE
ALTER
DROP
TRUNCATE
RENAME
2.DML (Data Manipulation Language)
Used to manipulate data.
Commands:
INSERT
UPDATE
DELETE
3. DQL (Data Query Language)
Used to retrieve data.
Command:
SELECT
4. DCL (Data Control Language)
Used for permissions.
Commands:
GRANT
REVOKE
5. TCL (Transaction Control Language)
Used for transaction management.
Commands:
COMMIT
ROLLBACK
SAVEPOINT

20)Difference betweeen ALTER and UPDATE
| ALTER                   | UPDATE               |
| ----------------------- | -------------------- |
| Changes table structure | Changes data in rows |
| Used on columns/tables  | Used on records      |
| DDL command             | DML command          |



21) Difference between DROP and TRUNCATE
| DROP                    | TRUNCATE          |
| ----------------------- | ----------------- |
| Deletes entire table    | Deletes only data |
| Table structure removed | Structure remains |
| Cannot rollback         | Faster operation  |


22)Delete rows where salary is less than average salary of department

23)Difference between GROUP BY and HAVING
| GROUP BY                      | HAVING               |
| ----------------------------- | -------------------- |
| Groups rows                   | Filters grouped data |
| Used with aggregate functions | Used after GROUP BY  |
